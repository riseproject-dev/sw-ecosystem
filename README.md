# RISE Software Ecosystem Knowledge Base

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under
the Linux Foundation that accelerates open-source software development for the
RISC-V architecture.

## Charter

In this repository, you'll find status report for different upstream projects on
RISC-V. This knowledge base is created and maintained using AI agents. It is used
to get a clearer picture of the status of the ecosystem to help prioritize work
on the many projects that make this ecosystem.
